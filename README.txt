# Occupational Risk Dashboard

This project is a Python-based tool designed to automate the evaluation of workplace hazards using a risk matrix approach. It bridges the gap between Occupational Health and Safety (OHS) and Data Science.

## Features
- **Automated Calculation**: Calculates Risk Levels by multiplying Probability and Consequence.
- **Categorization**: Automatically classifies risks as Tolerable, Moderate, Substantial, or Intolerable.
- **Data Visualization**: Generates a bar chart to visualize the distribution of risk levels within a company.

## Technical Stack
- **Language**: Python
- **Libraries**: Pandas (data manipulation), Matplotlib (visualization), Openpyxl (Excel integration).

## How to Use
1. Ensure `Dashboard_Pro.xlsx` is in the root directory.
2. Run `Dashboard_de_Excel.py`.
3. The script will output a summary of risks and display a chart.
